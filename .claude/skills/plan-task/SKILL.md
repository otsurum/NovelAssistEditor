# 実装計画立案（Phase 2）

計画書を**完成させてから**提示する。**1 画面（〜60 行）以内**、各セクション箇条書き 3〜5 行。

必ず含める: スコープ／スコープ外（理由付き）／検証可能な粒度の要件＋確認方法／**再利用する既存コード**（新規実装の前に grep で探す）。

```markdown
## タスク概要
（何を解決するか。1〜2 行）

## スコープ
- [ ] 対応する内容

## スコープ外
- 対応しない内容と、その理由

## 要件 / 受け入れ条件
- 満たすべき条件 ＋ 確認方法（テスト名 or 手動確認の手順）

## 実装方針
- 変更するファイル / 追加するモジュール
- 再利用する既存コード

## 想定リスク・確認事項
- 人間に確認が必要なポイント
```

**修正ループ:** 指摘があれば修正して再提示。**全文ではなく変更セクションだけを差分で示す。**

**完了条件:** 計画書が承認されている。承認まで実装コードを書かない。
